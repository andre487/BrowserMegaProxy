MegaProxy manages proxies you provide. Connect your own HTTP, HTTPS or SOCKS5 proxy, keep its configuration up to date and choose which sites use it. No proxy servers, VPN service or MegaProxy account are included.

For Firefox
Route by destination domain or by a tab’s top-level site, including its third-party requests. HTTPS proxies can receive credentials in the first CONNECT; HTTP may wait for a challenge. SOCKS5 supports username/password and proxy-side DNS. Private-window access is required for proxy control. Firefox Android is supported from version 142. Automatic, light and dark themes are available.

Experimental MASQUE requires Firefox 146+, is off by default and does not support username/password. CONNECT-TCP is tested; HTTP/3 through CONNECT-UDP is not confirmed.

For a masked HTTP/HTTPS proxy, configure the knock host supplied by its operator. It opens on connection and browser startup, in the background with saved credentials or actively without them, and closes after a successful load. Rejected saved credentials can open a correction dialog. SOCKS5 and MASQUE do not use knock.

• Switch profiles from the toolbar. Use Proxy, Direct or the browser’s System settings.
• Subscribe to a configuration URL with backup sources and optional Basic Auth over HTTPS. Pause automatic updates or refresh manually; failed updates keep the working configuration. Use only trusted sources: backup URLs receive the same configured credentials.
• Proxy all sites, choose domains with wildcard rules or use automatic Podkop domain lists. Lists can update through your proxy. Local networks are bypassed by default.
• Check the exit IP, optional country and HTTPS loading time. Test routing rules without making a network request.
• Import MegaProxy, FoxyProxy, ZeroOmega, ProxyList or SuperProxy from a file or URL. Export MegaProxy version 8; HTTP profiles and HTTPS proxies with IPv6 host literals cannot be exported.
• Get connection-update notices and optionally enable system notifications. WebRTC restrictions require optional permission and may affect calls.
• Use English or Russian, profile colors and country flags, and drag to reorder profiles.

Privacy and control
Settings sync and password sync are enabled by default and can be disabled separately. Passwords are not separately encrypted by MegaProxy and are included in exports by default; you can exclude them. Request counters and the network monitor are local, enabled by default and can be disabled together. A local diagnostic log can be viewed, cleared and exported.

Optional service-history cleanup removes URLs opened in knock and connection-check tabs, including earlier visits to those URLs. It is off by default and requires history access.

Limits
One profile is active at a time. SOCKS4, client-side proxy chains, custom PAC scripts and automatic proxy failover are not supported. Unsupported imports show warnings. New connections use changed settings; existing connections may need a page reload or browser restart.
