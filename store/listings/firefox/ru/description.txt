MegaProxy управляет вашими HTTP-, HTTPS- и SOCKS5-прокси: обновляет конфигурацию по подписке с резервными URL, подключает списки Podkop и направляет через прокси выбранные домены, сайты или отдельные вкладки. Для HTTPS-прокси Firefox может отправлять сохранённые логин и пароль уже в первом CONNECT-запросе, в том числе при маскировке авторизации.

Переключайте профили из панели браузера или выбирайте прямое соединение и системные настройки прокси. Доступны автоматическая, светлая и тёмная темы.

• Подписки на конфигурации с резервными URL и необязательной Basic Auth по HTTPS. Редактируйте адреса, логин, пароль и интервал в одном блоке; приостанавливайте автоматические проверки, обновляйте вручную из настроек или панели расширения и отменяйте подписку, сохраняя профили. Неудачное обновление сохраняет последний рабочий конфиг. Источник может обновлять адреса подписки; локальные данные авторизации и параметры обновления сохраняются.
• Маршрутизация Firefox по доменам запросов, сайту верхнего уровня или отдельным вкладкам. HTTPS-прокси могут получать сохранённые реквизиты заранее; SOCKS5 поддерживает логин, пароль и разрешение DNS на прокси. Firefox для Android поддерживается с версии 142.
• Автоматические списки доменов из источников, используемых Podkop. Обновление можно направить через прокси. Неиспользуемые списки не скачиваются.
• Проксирование всех сайтов или ручной список доменов с поддержкой вайлдкардов. Локальные сети обходятся по умолчанию; обход можно отключить.
• Экспериментальный MASQUE в Firefox 146+: выключен по умолчанию, без логина и пароля. Сценарии CONNECT-TCP проверены; работа HTTP/3 через CONNECT-UDP не подтверждена.
• HTTP- и HTTPS-прокси с CONNECT, авторизацией по логину и паролю и необязательным knock host.
• SOCKS5 с разрешением DNS на прокси. Firefox поддерживает логин и пароль.
• Один выбранный профиль, имена, цвета и флаги стран. Меняйте порядок профилей перетаскиванием, в том числе на сенсорном экране.
• Проверка правил маршрутизации и подключения: внешний IP, страна и время загрузки HTTPS.
• Импорт MegaProxy, FoxyProxy, ZeroOmega, ProxyList и SuperProxy из файла или по URL. Экспорт в формате MegaProxy: HTTP-профили и HTTPS-прокси с IPv6-адресом не экспортируются; для SOCKS5 нужен совместимый клиент.
• Предупреждение при изменении активного прокси или правил, в том числе списков Podkop. Системные уведомления включаются отдельно и требуют необязательного разрешения.
• Необязательные ограничения WebRTC, контекстные меню страниц, русский и английский интерфейсы, светлая и тёмная темы.
• Синхронизация настроек средствами браузера. Синхронизация настроек и паролей включена по умолчанию; их можно отключить отдельно.
• Счётчики запросов и ограниченный по объёму монитор сети включены по умолчанию и могут быть отключены. Их данные остаются локальными. Отдельный локальный диагностический лог можно просматривать и экспортировать; лимит настраивается от 1 до 10 MiB.

MegaProxy управляет прокси, но не предоставляет прокси-серверы, VPN-подписку или учётную запись. Для работы нужен собственный совместимый прокси. При импорте неподдерживаемых полей конфигурации выводится предупреждение. SOCKS4, цепочки прокси, пользовательские PAC-скрипты и автоматическое переключение на резервные прокси не поддерживаются.

Сохранённые реквизиты передаются заранее там, где это поддерживает API прокси Firefox; автоматический knock при этом не запускается. Кнопка Knock позволяет вручную открыть настроенный host через активный прокси. Без сохранённых реквизитов настроенный knock host открывается для стандартного диалога авторизации браузера. Для API настроек прокси Firefox требуется разрешение работы в приватных окнах.

Firefox использует обновлённые настройки для следующих запросов; существующие подключения могут потребовать перезагрузки страниц. При удалении выбранного профиля подписка выбирает замену, сохраняя режим Direct/System.
