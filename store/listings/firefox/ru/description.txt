MegaProxy позволяет выбирать, когда браузер использует ваш HTTP-, HTTPS- или SOCKS5-прокси. Сохраните несколько профилей и выбирайте один из панели браузера либо переключайтесь на прямое соединение или системные настройки прокси.

• HTTP- и HTTPS-прокси с CONNECT, авторизацией по логину и паролю и необязательным knock host.
• SOCKS5 с разрешением DNS на прокси. Firefox поддерживает логин и пароль.
• Один выбранный профиль, имена, цвета и флаги стран. Меняйте порядок профилей перетаскиванием, в том числе на сенсорном экране.
• Проксирование всех сайтов или ручной список доменов с поддержкой вайлдкардов. Локальные сети обходятся по умолчанию; обход можно отключить.
• Автоматические списки доменов из источников, используемых Podkop. Обновление можно направить через прокси. Неиспользуемые списки не скачиваются.
• Проверка правил маршрутизации и подключения: внешний IP, страна, протокол и время загрузки HTTPS.
• Импорт MegaProxy, FoxyProxy, ZeroOmega, ProxyList и SuperProxy из файла или по URL. Экспорт в формате MegaProxy: HTTP-профили и HTTPS-прокси с IPv6-адресом не экспортируются; для SOCKS5 нужен совместимый клиент.
• Подписки на конфиги с резервными URL, необязательной Basic Auth по HTTPS и настраиваемым интервалом. Автоматические проверки можно приостановить; «Обновить сейчас» доступно в настройках и popup. Ошибки обновления сохраняют последний рабочий конфиг.
• Предупреждение при изменении активного прокси или правил, в том числе списков Podkop. Системные уведомления включаются отдельно и требуют необязательного разрешения.
• Необязательные ограничения WebRTC, контекстные меню страниц, русский и английский интерфейсы, светлая и тёмная темы.
• Синхронизация настроек средствами браузера. Синхронизация настроек и паролей включена по умолчанию; их можно отключить отдельно.
• Счётчики запросов и ограниченный по объёму монитор сети включены по умолчанию и могут быть отключены. Их данные остаются локальными. Отдельный локальный диагностический лог можно просматривать и экспортировать; лимит настраивается от 1 до 10 MiB.

MegaProxy управляет прокси, но не предоставляет прокси-серверы, VPN-подписку или учётную запись. Для работы нужен собственный совместимый прокси. При импорте неподдерживаемых полей конфигурации выводится предупреждение. SOCKS4, цепочки прокси, пользовательские PAC-скрипты и автоматическое переключение на резервные прокси не поддерживаются.

В Firefox также доступна маршрутизация по сайту верхнего уровня и отдельным вкладкам. Сохранённые реквизиты передаются заранее там, где это поддерживает API прокси Firefox; действие knock при этом отключено. Адрес knock host можно редактировать и сохранить для подключения без сохранённых реквизитов. Без сохранённых реквизитов настроенный knock host открывается для стандартного диалога авторизации браузера. Для API настроек прокси Firefox требуется разрешение работы в приватных окнах.

Firefox использует обновлённые настройки для следующих запросов; существующие подключения могут потребовать перезагрузки страниц. При удалении выбранного профиля подписка выбирает замену, сохраняя режим Direct/System. Firefox для Android поддерживается с версии 142. Экспериментальный MASQUE доступен с Firefox 146, выключен по умолчанию и не поддерживает логин/пароль; сценарии CONNECT-TCP проверены, работа HTTP/3 через CONNECT-UDP не подтверждена.
