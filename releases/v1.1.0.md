## English

- Improved profile editing, interface feedback, and keyboard navigation.
- The empty popup now provides shortcuts to create a profile or import a configuration.
- Added SOCKS5 support. Firefox uses its native authentication flow; Chromium’s credential-entry options follow its UI limits.
- Firefox users can enable experimental anonymous MASQUE support in settings.
- Imported profiles without a color are assigned distinct colors.
- HTTP 5xx errors show more detail, and temporary configuration-download failures are retried.
- Country flags display more consistently across browsers.

## Русский

- Улучшены редактирование профилей, обратная связь интерфейса и навигация с клавиатуры.
- В пустом всплывающем окне появились быстрые действия для создания профиля и импорта конфигурации.
- Добавлена поддержка SOCKS5. В Firefox используется встроенная аутентификация; в Chromium ввод учётных данных ограничен возможностями интерфейса браузера.
- В Firefox можно включить экспериментальную поддержку анонимного MASQUE в настройках.
- Импортированным профилям без цвета назначаются разные цвета.
- Для ошибок HTTP 5xx отображаются дополнительные сведения, а временные сбои при загрузке конфигурации повторяются.
- Отображение флагов стран стало более единообразным в разных браузерах.
