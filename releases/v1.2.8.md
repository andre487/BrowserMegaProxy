## English

- Firefox now opens the configured knock host on connection and browser startup even with saved credentials, using a background tab so masked HTTP/HTTPS proxies can expose rejected credentials and trigger the correction dialog.
- Configuration imports now accept `proxy.knockHost`, prefer it over legacy `browser.knockHost`, and disable knock when it is explicitly empty, including when merging profiles; HTTPS profile exports include both fields for compatibility with older clients.

## Русский

- Firefox теперь открывает настроенный knock host при подключении и запуске браузера даже с сохранёнными реквизитами, используя фоновую вкладку, чтобы HTTP/HTTPS-прокси с маскировкой могли сообщить об отклонённых реквизитах и вызвать диалог их исправления.
- Импорт конфигураций теперь принимает `proxy.knockHost`, отдаёт ему приоритет над устаревшим `browser.knockHost` и отключает knock при явно пустом значении, в том числе при объединении профилей; экспорт HTTPS-профилей включает оба поля для совместимости со старыми клиентами.
