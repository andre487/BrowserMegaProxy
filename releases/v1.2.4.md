## English

- Connection checks now prefer Cloudflare for the exit IP and country, fall back to other services when needed, and display HTTP and TLS versions when Cloudflare provides them.
- Firefox now accepts SOCKS5 usernames containing colons when saving profiles or importing and exporting configurations, while Chromium still does not support authenticated SOCKS5.
- Importing a version 8 configuration now rejects malformed browser routing fields, such as null lists or duplicate domain and source entries, instead of silently normalizing them.
- Profile reordering now uses a centered six-dot drag icon instead of a text symbol.
- Profile cards no longer repeat the “Active” label beside the proxy address.

## Русский

- Проверка подключения теперь в первую очередь получает внешний IP и страну через Cloudflare, при необходимости использует другие сервисы и показывает версии HTTP и TLS, если Cloudflare их сообщает.
- Firefox теперь принимает имена пользователей SOCKS5 с двоеточиями при сохранении профилей, импорте и экспорте конфигураций, а Chromium по-прежнему не поддерживает SOCKS5 с авторизацией.
- При импорте конфигурации версии 8 некорректные поля маршрутизации браузера, например списки со значением null или повторяющиеся домены и источники, теперь отклоняются вместо неявной нормализации.
- Для изменения порядка профилей теперь используется выровненный по центру значок из шести точек вместо текстового символа.
- В карточках профилей больше не дублируется отметка «Активный» рядом с адресом прокси.
