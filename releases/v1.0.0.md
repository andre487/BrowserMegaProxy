## English

- **MegaProxy 1.0.0** provides proxy routing with site exclusions, proxy authentication, and knock-based authentication flows.
- Review private-window access status and setup instructions in the extension.
- Proxy authentication now has a focused dialog; saved credentials are verified before they are accepted. If credentials are empty, the browser’s native proxy-authentication prompt is used.
- **Chromium:** restart the browser after changing proxy credentials.
- **Firefox:** edit the knock host even when credentials are saved.
- Connection-check failures are displayed in the check result.

## Русский

- **MegaProxy 1.0.0** предоставляет маршрутизацию через прокси с исключениями для сайтов, аутентификацию прокси и сценарии аутентификации с помощью knock.
- В расширении можно проверить доступ к приватным окнам и посмотреть инструкции по настройке.
- Для аутентификации прокси появилось отдельное диалоговое окно; сохранение учётных данных выполняется после проверки. Если данные не указаны, используется встроенный запрос браузера для аутентификации прокси.
- **Chromium:** после изменения учётных данных прокси требуется перезапустить браузер.
- **Firefox:** адрес knock-хоста можно редактировать и при сохранённых учётных данных.
- Ошибки проверки соединения отображаются в результате проверки.
