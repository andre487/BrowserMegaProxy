## English

- Affected tabs now refresh after a Knock action.
- Streamlined profile controls with circular icon buttons, updated Select/Knock placement, and preserved focus during profile actions.
- Added a login icon to Select buttons in Settings and aligned their widths with Knock buttons.
- Firefox: manual Knock actions are now available.

## Русский

- После действия Knock обновляются затронутые вкладки.
- Упрощены элементы управления профилями: круглые кнопки с иконками, обновлённое расположение Select/Knock и сохранение фокуса при действиях с профилями.
- В настройках кнопки выбора профиля получили иконку входа; их ширина выровнена с кнопками Knock.
- Firefox: теперь можно запускать Knock вручную.
