# Installation badges

Official, unmodified store badges linked from the installation table in the project README.

- `chrome-web-store.png`: [Chrome Web Store branding guidelines](https://developer.chrome.com/docs/webstore/branding), [medium badge with border](https://developer.chrome.com/static/docs/webstore/branding/image/iNEddTyWiMfLSwFD6qGq.png). Google and Chrome Web Store marks belong to Google LLC.
- `firefox-addons.png`: [Mozilla promotion guide](https://extensionworkshop.com/documentation/publish/promoting-your-extension/), [Get the add-on badge](https://extensionworkshop.com/assets/img/documentation/publish/get-the-addon-178x60px.dad84b42.png). Firefox marks belong to Mozilla.

These third-party brand assets retain their respective owners’ rights; the repository MIT license does not grant trademark rights. Display the badges with their original aspect ratios and link them to MegaProxy’s corresponding store listings.

## Social preview

`social-preview.png` (1280×640) is rendered from the pinned `social-preview.svg`
in [MegaProxyIdentity](https://github.com/andre487/MegaProxyIdentity), under CC0-1.0
(see `extension/icons/LICENSE`). Run `npm run renew-identity` to update the source
snapshot and regenerate this PNG together with extension icons and store branding.
Run `node scripts/renew-toolbar-icons.mjs` to regenerate them offline.
